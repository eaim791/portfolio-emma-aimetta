Política de privacidad

Agency OS · Última actualización: 18 de octubre de 2026

Agency OS es una herramienta de gestión de clientes y correo creada y operada por Emma Aimetta (EAIM Lab.). Esta política explica qué datos usa la aplicación cuando conectás tu cuenta de Google, para qué los usa y cómo podés controlarlos.

Qué datos de Google usa la aplicación

Cuando conectás Gmail, la aplicación te pide estos permisos de Google:

  • Tu dirección de correo (permisos openid y email), para saber qué cuenta conectaste.
  • Leer tus mensajes de Gmail (gmail.readonly), para traer a la aplicación las respuestas de las personas con las que te estás comunicando y mantener cada conversación en su hilo.
  • Enviar correos en tu nombre (gmail.send), para enviar los mensajes que vos revisás y aprobás.

Para qué se usan

Los datos de Google se usan únicamente para ofrecer las funciones que ves dentro de la aplicación: mostrar conversaciones, enviar respuestas cuando vos lo ordenás y registrar el estado de cada envío. No se usan para publicidad, no se venden y no se comparten con terceros.

El uso que hace Agency OS de la información recibida de las API de Google cumple con la Política de datos del usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado. Los datos de Gmail no se utilizan para entrenar modelos de inteligencia artificial o aprendizaje automático generalizados.

Cómo se guardan

  • La clave de acceso que entrega Google (token de actualización) se guarda cifrada en el servidor y nunca se muestra en pantalla ni en registros.
  • Los mensajes y conversaciones se guardan en la base de datos de tu propio espacio de trabajo, accesible solo para vos mediante inicio de sesión.
  • La aplicación nunca te pide tu contraseña de Google: el acceso se otorga en la pantalla oficial de Google.

Cuánto tiempo se conservan

Los datos se conservan mientras uses la aplicación. Si desconectás tu cuenta, la clave de acceso se elimina y se revoca el permiso. Los mensajes ya guardados se eliminan cuando lo solicites.

Tus controles

  • Desconectar tu cuenta desde Configuración › Integraciones en la aplicación.
  • Revocar el acceso en cualquier momento desde myaccount.google.com/permissions.
  • Pedir la eliminación de tus datos escribiendo al contacto indicado abajo.

Cambios en esta política

Si esta política cambia, se actualizará esta página y la fecha de arriba.
