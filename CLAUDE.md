# Emma Aimetta — Portafolio (versión vigente) — contexto del proyecto

Portafolio personal interactivo de Emma Aimetta (Front-End Developer y UX/UI Designer). Diseño editorial, minimalista y premium en tonos lino, oliva y ámbar; español/inglés; página con todos los proyectos y vitrina de webs y automatizaciones con planes y precios. En vivo: https://portfolioeaim.vercel.app (repo `portfolio-emma-aimetta`).

## Stack
React · Vite · GSAP (ScrollTrigger) · Lenis. Tipografía Bodoni Moda + Albert Sans.

## Comandos
`npm install` · `npm run dev` · `npm run build` · `npm run preview`

## Estructura
`src/components`, `src/data`, `src/hooks`, `src/lib`, `src/styles` · `public/`, `img/` · `docs/screenshots/` · `scripts/`.

## Reglas de contenido
- Los proyectos privados (AIGO, Agency OS, Lystra) solo muestran una vista previa, sin enlace; MDM Surgery es el único que se abre.
- Loader "retrato que se revela" solo en la primera visita de la sesión; galería de proyectos con scroll horizontal "pinned" (se apila en móvil).
